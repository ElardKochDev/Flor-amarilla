# Audio

Los efectos de sonido y la música de caja de música se **sintetizan en tiempo real con Web Audio** (`src/game/audio.ts`), así que no se necesitan archivos y el juego carga más rápido.

Si quieres reemplazarlos por archivos propios (`.mp3` / `.ogg`), colócalos aquí y cárgalos desde `audio.ts`.
